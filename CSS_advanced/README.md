# CSS Advanced

## Description

This project focuses on advanced CSS concepts used to build modern and responsive web pages.

Using a provided HTML structure, we progressively add styles to create the Techium website while learning how CSS works behind the scenes.

## Learning Objectives

At the end of this project, you should be able to explain:

- Selectors, properties and values
- The difference between block and inline elements
- CSS reset techniques
- CSS variables
- Inline, embedded and external CSS
- Float-based grid systems
- Webfont icons and SVG icons
- Pseudo-classes and pseudo-elements
- Background gradients
- CSS animations
- CSS transforms (2D and 3D)
- Vendor prefixes

## Requirements

- Ubuntu 20.04 LTS
- Google Chrome 78.x
- Allowed editors:
  - vi
  - vim
  - emacs
  - VSCode
  - Atom
- All files must end with a new line
- All CSS files must begin with a comment describing the task
- Code must be W3C compliant
