# HTML Advanced

## Description

This project is part of the **Holberton School Web Front-End** curriculum.

The objective is to learn the fundamentals of HTML5 by building the structure of a webpage using semantic HTML elements, following W3C standards and best practices.

No CSS or JavaScript is used in this project. The focus is entirely on creating clean, valid, and well-structured HTML documents.

---

## Learning Objectives

By completing this project, I learned how to:

* Create the skeleton of an HTML5 document.
* Use semantic HTML elements.
* Structure a webpage correctly.
* Organize headings properly.
* Create lists and tables.
* Embed images, videos, audio, and external content.
* Understand the purpose of semantic tags such as:

  * `header`
  * `main`
  * `section`
  * `article`
  * `aside`
  * `nav`
  * `footer`
* Write HTML that is compliant with W3C standards.
